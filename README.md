<h1 data-importer="text" align="left">Roblox Ban Bot in Discord</h1>

###

<p data-importer="text" align="left">Discord bot for moderating Roblox games directly from your Discord server. Supports multiple games and API keys simultaneously.</p>

###

<h3 data-importer="text" align="left">⚙️ Commands</h3>

###

<p data-importer="text" align="left">🔨 /ban — Permanently ban a player across all places</p>

<h3 data-importer="text" align="left">📜 .env Example</h3>

###

<p data-importer="text" align="left">DISCORD_TOKEN=your_discord_bot_token<br>GUILD_ID=your_discord_server_id<br><br>#You can use multiple api keys and places<br>ROBLOX_API_KEY_1=your_roblox_api_key<br>UNIVERSE_ID_1_1=your_universe_id<br>UNIVERSE_ID_1_2=another_universe_id<br><br>ROBLOX_API_KEY_2=your_roblox_api_key<br>UNIVERSE_ID_2_1=your_universe_id<br>UNIVERSE_ID_2_2=another_universe_id<br><br>TAG_CLOSED=tag_id<br>TAG_BANNED=tag_id<br>TAG_REVIEWED=tag_id</p>
